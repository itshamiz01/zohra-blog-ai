# Topic Clusters & Pillar Strategy

## Overview

A topic cluster groups interconnected search opportunities around a central **Pillar** topic, supported by granular cluster articles.

---

## Cluster Structure

```text
PILLAR: Complete Guide to Model X (Explainer / Architecture)
  ├── SUPPORTING: Model X Pricing & Tiers (Commercial)
  ├── SUPPORTING: How to Use Model X for YouTube Creators (Tutorial)
  ├── SUPPORTING: Model X vs Runway Gen-3 (Comparison)
  ├── SUPPORTING: Model X API Integration Tutorial (Developer)
  └── SUPPORTING: Troubleshooting Model X Latency Issues (Troubleshooting)
```

- **Pillar vs Supporting Classification**: An opportunity is marked as `pillar`, `supporting`, `standalone`, `news`, or `update`.
- Prevents producing fragmented, competing pillar pages.
- Sets up the topical graph required in later stages for contextual internal linking and siloed authority building.
